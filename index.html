코드 입력

악보의 마디를 누르면 입력창이 열려요. 한 마디에 코드가 여러 개면 띄어 쓰세요 (예: Dm7 G7). 앞 마디와 같으면 % 또는 -. 같은 코드를 연달아 쓰면(C D Em Em) 그만큼 칸을 넓게 차지해요. 점(·)과 -는 C.D-Em처럼 직접 쓰면 그대로 찍혀요. 텐션은 x² 버튼(^) 뒤에 쓰면 위첨자로 올라가요 (예: C7^b9,13). 도돌이표와 1·2번 괄호도 입력창에서 마디마다 정해요. 같은 괄호를 연달아 붙이면 하나로 이어져요.

송폼 구간

구간을 등록하면 해당 마디가 색으로 칠해져요. 가운데 칸에 V1, V2, Int/V처럼 악보에 쓸 이름을 직접 적을 수 있고, 오른쪽 색 버튼을 누르면 범례 색 중에서 고르거나 원하는 색을 직접 고를 수 있어요.

색 진하기

내 송폼 목록

V1, V2, Int/V처럼 자주 쓰는 송폼을 이름과 색으로 저장해 두면, 송폼 구간 종류에서 ★로 골라 쓸 수 있어요. 모든 곡에서 같이 쓰여요.

색상 범례

오른쪽 칸은 악보 왼쪽 섹션 칸에 쓸 약어예요. 한 색을 두 섹션이 같이 쓰면 Int/Out처럼 /로 나눠 적으세요. 첫 글자는 자동으로 대문자가 돼요.
